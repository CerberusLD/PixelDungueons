# Pixel Dungeons

Proyecto Godot gestionado por Cerberus Engine.

## Cómo trabajar

1. Abre el editor: `cerberus editor --project .`
2. Llama herramientas: `cerberus call scene_tree`
3. Ejecuta y captura: `cerberus call project_run` y `cerberus call runtime_capture_screenshot`

Las escenas y scripts se editan a través de las tools; no edites .tscn a mano.
